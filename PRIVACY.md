# Privacy

## What this project collects

Nothing.

## In more detail

- There is no server, no account system and no login.
- The published site at GitHub Pages is static. It loads no fonts, scripts,
  images or stylesheets from any third party, and it sends no analytics or
  telemetry anywhere. Everything it needs is inlined or served from the same
  origin.
- No cookies are set, and no local storage is written.
- No personal data appears in the repository. Every data file under
  `fixtures/` is synthetic output of the deterministic generators in
  `econospec/dgp.py`, produced from fixed seeds and committed as CSV.
- No university system is accessed, and no student, staff or enrolment record
  exists anywhere in this project.

## What GitHub itself sees

Visiting the site or the repository involves GitHub, which keeps its own
server logs under its own privacy statement. That is outside the control of
this project, and it is the only data collection involved in using it.
